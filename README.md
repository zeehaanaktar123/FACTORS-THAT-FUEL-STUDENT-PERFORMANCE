# 🎓 Student Performance SQL Analysis

## 📌 Project Overview

This project analyzes student performance data using SQL to investigate how study habits and extracurricular participation relate to exam performance.

The analysis focuses on transforming business/research questions into SQL queries and extracting meaningful patterns from the dataset.

## 🎯 Objectives

* Analyze average exam scores based on study hours
* Compare study-hour ranges and average performance
* Investigate the relationship between study hours and extracurricular participation
* Rank students based on exam performance
* Identify high-performing student segments

## 🛠️ Tools & Technologies

* SQL
* PostgreSQL
* Aggregate Functions
* CASE Statements
* GROUP BY
* Window Functions
* DENSE_RANK()

## 🔍 SQL Techniques Demonstrated

### Aggregation

Used `AVG()` with `GROUP BY` to compare average exam performance across study-hour groups.

### Conditional Segmentation

Used `CASE WHEN` statements to categorize students into study-hour ranges.

### Window Functions

Used `DENSE_RANK()` to rank students based on exam scores.
