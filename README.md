# FACTORS-THAT-FUEL-STUDENT-PERFORMANCE
1. This is SQL query based project on Student performance dataset. 
2. Clean the data using Python and transfer it to PostgreSQL. Used it to Analyze the data, identifying pattern and give answer of data related queries. 
3. Used CASE-functions to answer questions like how study hours and extracurricular activity affect exam scores or what is the optimum study hour for student life. 
4. Used  window-functions to rank the students based on exam scores.
5. Project is done in Datacamp Notebook.
